## 已確認的方向
**範圍**
- 玩家：自己＋同事（公司內的業餘專案）；第一版單人，合作交易留到多人版（STK-003 Should）
- 平台：桌機 Chrome／Edge；發佈在 GitHub Pages，「不宣傳但可公開」，repo 公開；使用者確認公司能開 github.io
- 14 項 Must 能力分兩個里程碑：v0.1 最小循環（在線掛機、離線結算、存檔、上班模式、設定、設施、冒險）；v1.0 補齊，M1＝走到第一次轉生
- 核心循環：設施與冒險互相供應；Boss 只能在線手動打，打倒才解鎖下一區域；不打也會慢慢進步

**掛機與結算**
- 在線與離線同一套「經過時間 → 收益」公式，離線套用折扣與上限；中途有事件就分段計算，任意切法結果差距 1% 內
- 掉落用累積期望值，滿 1 給 1 件，不用亂數
- 兩次 tick 間隔超過 120 秒就算離線（電腦睡眠、分頁凍結、當掉都一樣）
- 改系統時間作弊：單人版不防，只擋時間倒退
- 平衡目標：典型玩家（平日掛 8 小時、其餘離線）第一次轉生在第 7～14 天

**存檔**
- localStorage（鍵名加前綴）每 30 秒＋分頁隱藏時存；匯出匯入檔案；3 天沒匯出就不顯眼地提醒
- 多分頁只有一個主控分頁；壞檔不覆蓋、不自動開新遊戲；寫入失敗要警告
- 匯入前確認並自動備份現有進度，匯入後不做離線結算

**上班模式**
- 隱藏鍵 1 秒內偽裝成靜態試算表樣板，換分頁標題與圖示；記住偽裝狀態，可設「開啟時預設偽裝」
- 預設靜音，偽裝與背景時不播放聲音；只有隱藏鍵有快速鍵
- 「主管」不列利害關係人，改寫成玩家自我約束「不影響工作」（STK-006）

**技術**
- 保留北境求生的「純 JS、無相依、不建置、Node 內建工具」；不沿用 canvas、classic script、全域狀態
- ES modules；`load` 之後零網路請求（圖示與偽裝素材內嵌）
- 測試：`core` 用 `node:test`，外殼複製北境求生的 CDP 瀏覽器測試；Actions 測試通過才發佈
- 單檔備案：公司擋 github.io 時用 Node 內建工具串成單一 HTML 檔，只限發佈
